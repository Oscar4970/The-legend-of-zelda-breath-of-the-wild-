# BOTW Android — laboratorio de compatibilidad

Proyecto experimental Android ARM64 para investigar un futuro port nativo de *The Legend of Zelda: Breath of the Wild*. **No es el juego ni un port jugable.** Este proyecto prueba gráficos OpenGL ES 3, consulta Vulkan y analiza ejecutables NSO sin cifrar de copias propias.

El código se añadirá a este repositorio y se compilará mediante GitHub Actions. No subas ROMs, claves ni archivos de Nintendo; este repositorio actualmente es público.
